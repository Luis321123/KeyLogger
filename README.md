## Que es un keylogger?

Los keyloggers son herramientas que
registran cada pulsación en un teclado, usados tanto con fines legítimos como
maliciosos. Este proyecto combina estudio teórico y desarrollo práctico, enfocado
en sistemas operativos como Windows, Linux y macOS.


## Usos y riesgos 
Mientras que, en entornos controlados, como en el monitoreo parental o
empresarial, los keyloggers pueden ser utilizados para fines legítimos, su uso
más conocido y nefasto es por parte de ciberdelincuentes para el robo de
información sensible. Esto incluye desde contraseñas y datos de tarjetas de
crédito hasta conversaciones privadas, lo que representa un grave riesgo para
la privacidad y la seguridad financiera de las personas
